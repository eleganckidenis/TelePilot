# TelePilot

[Polski](README.pl.md) · [Download](https://github.com/eleganckidenis/TelePilot/releases/latest)

TelePilot is a free, keyboard-friendly IPTV player for Windows and Mac. Use your own M3U or M3U8 playlists to watch live TV, browse the programme guide, save favourites and record shows. Catch-up is available when your IPTV provider supports it.

## Install

- **Windows 10 (22H2) or Windows 11, Intel/AMD:** Run the `win-x64-setup.exe` installer. Administrator access is required.
- **macOS 14 or later, Apple Silicon:** Open the `Apple-Silicon.dmg` file and drag TelePilot to Applications.

The Windows installer is unsigned. The Mac app is signed ad hoc and has no Apple notarization. SHA-256 checksums are provided on the download page.

## Get started

1. On your first launch, choose a language. TelePilot uses the system language by default, with English as the fallback. You can change this in **Settings** and restart TelePilot to apply it.
2. In **File → Playlist Manager**, add a playlist from a file or web address. This window opens automatically the first time you use TelePilot.
3. Choose a channel and press **Enter**. See **Help** for keyboard shortcuts.

TelePilot checks for a new release at startup. It downloads and verifies the right package, then offers to open it for installation.

TelePilot does not provide channels, playlists or IPTV subscriptions.
