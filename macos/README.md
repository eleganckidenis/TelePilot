# TelePilot for macOS

[English instructions](../README.md) · [Instrukcja po polsku](../README.pl.md)

TelePilot runs on Apple Silicon Macs with macOS 14 or later. Open the DMG from the [latest release](https://github.com/eleganckidenis/TelePilot/releases/latest) and drag TelePilot to Applications.

- **File → Playlist Manager** opens your playlists. Press **Enter** on a channel to play it.
- **TelePilot → Settings** (`⌘,`) contains language and playback settings.
- **Help** lists the keyboard shortcuts.
