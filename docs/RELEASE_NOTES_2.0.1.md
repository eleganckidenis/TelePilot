## English

- The language you save in **Settings** now takes effect when you restart TelePilot.
- There is a native installer for **Windows 11 ARM64**, including the appropriate .NET runtime and VLC libraries. Setup downloads verified native FFmpeg if needed.
- Removing an inactive playlist on Windows keeps the current source and its channel list. Playlist import failures are reported in the app.
- The bundled VLC engine is now 3.0.24, with [VideoLAN’s security fixes](https://images.videolan.org/security/sb-vlc3024.html).

**Download:** Use `TelePilot-2.0.1-win-x64-setup.exe` for Intel/AMD Windows, `TelePilot-2.0.1-win-arm64-setup.exe` for Windows 11 on ARM, or `TelePilot-2.0.1-Apple-Silicon.dmg` for an Apple Silicon Mac running macOS 14 or later. To switch from the x64 edition running on ARM, download the ARM64 installer manually. The updater continues to follow the architecture of your installed edition.

## Polski

- Język zapisany w **Ustawieniach** jest teraz używany po ponownym uruchomieniu TelePilota.
- Dostępny jest natywny instalator dla **Windows 11 ARM64** z odpowiednim środowiskiem .NET i bibliotekami VLC. Instalator w razie potrzeby pobiera zweryfikowane, natywne FFmpeg.
- Usunięcie nieaktywnej playlisty w Windows zachowuje bieżące źródło i listę kanałów. Błędy dodawania playlist są zgłaszane w aplikacji.
- Dołączony silnik VLC 3.0.24 zawiera [poprawki bezpieczeństwa VideoLAN](https://images.videolan.org/security/sb-vlc3024.html).

**Pobieranie:** Wybierz `TelePilot-2.0.1-win-x64-setup.exe` dla Windows na procesorze Intel/AMD, `TelePilot-2.0.1-win-arm64-setup.exe` dla Windows 11 na ARM albo `TelePilot-2.0.1-Apple-Silicon.dmg` dla Maca z Apple Silicon i macOS 14 lub nowszym. Aby przejść z wersji x64 używanej na ARM na wersję natywną, pobierz instalator ARM64 ręcznie. Aktualizator dobiera paczkę według architektury zainstalowanego wydania.

The Windows installers are unsigned. The macOS app is signed ad hoc without Apple notarization. / Instalatory Windows są niepodpisane. Aplikacja macOS ma podpis ad-hoc bez notaryzacji Apple.
