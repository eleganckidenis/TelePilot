## English

- **Playlist Manager:** add, select, refresh and remove sources from **File → Playlist Manager**. New users see this window automatically.
- **English and Polish:** choose the language at first launch or in Settings. The Windows installer also offers both languages and suggests the system language.
- **Updates:** TelePilot checks at launch, downloads the correct package from GitHub Releases and verifies its SHA-256 checksum before offering to open it.

**Download:** On Windows 10 (22H2) or Windows 11 with Intel/AMD, run `TelePilot-2.0.0-win-x64-setup.exe` as an administrator. On macOS 14 or later with Apple Silicon, open `TelePilot-2.0.0-Apple-Silicon.dmg` and drag TelePilot to Applications. Quit TelePilot before replacing it. Updating preserves your playlists, favourites and settings.

The Windows installer is unsigned. The Mac app is signed ad hoc without Apple notarization. SHA-256 checksums and source archives are attached. TelePilot does not include IPTV channels or subscriptions.

## Polski

- **Menedżer playlist:** dodawanie, wybór, odświeżanie i usuwanie źródeł jest teraz w **Plik → Menedżer playlist**. Nowym użytkownikom to okno otworzy się automatycznie.
- **Polski i angielski:** język wybierzesz przy pierwszym uruchomieniu lub w Ustawieniach. Instalator Windows także udostępnia oba języki i proponuje język systemu.
- **Aktualizacje:** TelePilot sprawdza nową wersję przy uruchomieniu, pobiera odpowiednią paczkę z GitHub Releases i sprawdza jej sumę SHA-256 przed zaproponowaniem otwarcia.

**Pobieranie:** W Windows 10 (22H2) lub Windows 11 na komputerze Intel/AMD uruchom `TelePilot-2.0.0-win-x64-setup.exe` z uprawnieniami administratora. Na macOS 14 lub nowszym z Apple Silicon otwórz `TelePilot-2.0.0-Apple-Silicon.dmg` i przeciągnij TelePilot do folderu Programy. Zamknij aplikację przed jej zastąpieniem. Aktualizacja zachowuje playlisty, ulubione i ustawienia.

Instalator Windows nie jest podpisany cyfrowo. Aplikacja na Maca ma podpis ad-hoc bez notaryzacji Apple. W załącznikach są sumy SHA-256 i archiwa źródeł. TelePilot nie zawiera kanałów ani abonamentu IPTV.
